Everything is also on Tailscale now, so I can reach any of it from outside the house.

## Platform

- Tailscale on every host.
- Monitoring: Grafana Alloy on every host ships logs and metrics to Loki and Prometheus on Rope, with Grafana and Alertmanager on top. UptimeRobot watches the public sites.
- Backups: every host runs Borg to Brook, and Brook copies the Borg repository to Google Cloud Storage daily.
- Postgres and Redis on Rope.
- A mail server ([docker-mailserver](https://github.com/docker-mailserver/docker-mailserver)) on Mist, plus Parse DMARC for DMARC reports.
- fail2ban on Mist.
- Maestral on Brook to keep a copy of Dropbox.
- All of it is OpenTofu and docker compose in a single repo.

## Media (Rope)

- [RomM](https://github.com/rommapp/romm) for game ROMs.
- [slskd](https://github.com/slskd/slskd) for Soulseek.
- [spotify-to-plex](https://github.com/jjdenhertog/spotify-to-plex) to sync playlists into Plex.
- [GYB](https://github.com/GAM-team/got-your-back) to back up Gmail.
- stream-harvestarr and letterboxd-list-radarr, two small tools of mine for feeding the Servarr stack.
- FlareSolverr for Prowlarr.

## AI

- OpenCode and OpenChamber on Mist, a hosted coding agent at opencode.natwelch.com.

## Upcoming: Kiln

Kiln is a new box with a Tesla P40. It will run [Ollama](https://ollama.com/) with `qwen3-coder:30b` and `ornith:35b`, and OpenCode and OpenChamber move to it from Mist. Mist's Caddy will keep serving opencode.natwelch.com and proxy it to Kiln. It gets the same Alloy, Borg, and cron setup as the other hosts, plus a GPU exporter so I can watch the P40 in Grafana.

Also upcoming is a [LiteLLM](https://www.litellm.ai/) proxy on Mist, so all of my apps send LLM calls through one place.
